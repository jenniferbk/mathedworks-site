TinkerPlots

Paid desktop software for grades 4 and up in which students build their own graphs from data icons and design probability simulations, with free activities and teacher notes.

Before you use it

  • Cost: licenses are priced per computer, at $14 for one year or a one-time license of $29 (1–49 computers), $19 (50–99) or $15 (100+), as set by the publisher's order page on Oct 25, 2026. Without a license the program runs in Preview mode; the site does not say on that page what Preview mode limits.
  • TinkerPlots is a downloadable desktop program for Windows or Mac. Version 3.0 runs on macOS 10.13 or later and is required from 10.15; version 2.3 covers older systems. The Mac requirements say "Intel based system" and do not mention Apple Silicon. Chromebooks, iPads and Android devices need Chrome Remote Desktop connected to a Windows or Mac computer.
  • Version 3.0 (2020) was rewritten from scratch and uses a new file format (.tp3); the free activities post separate files for version 2 and version 3.
  • Students need a computer for the plotting part of each activity. The activity we read assumes students have seen the "TinkerPlots Basics" movie, cites the Common Core State Standards and is copyright 2012 Key Curriculum Press.
  • The developers describe it for students from middle school through university (grades 4 and up); the free activities we saw are for grades 5–8.

Try one lesson

Who Has the Heaviest Backpacks? tinkerplots.com

  • Grades 3–8
  • Comparing groups
  • One class period
  • Free, no login

Students predict typical backpack weights, then open a TinkerPlots file of data on students in grades 1, 3, 5 and 7 and make graphs to decide whether students in higher grades, and girls or boys, carry heavier backpacks, explaining how each plot backs up their conclusion.

You need: A worksheet for each student, the Heaviest Backpacks file and computers with TinkerPlots.

The activity files are free, but TinkerPlots itself is paid software that runs in Preview mode until you buy a license.

What a teacher gets

TinkerPlots is a data visualization and modeling program for grades 4 and up, first released in 2004 and sold today by Learn Troop. Instead of a menu of graph types, students order, stack and separate data icons, building standard plots (pie charts, histograms, scatterplots) or plots of their own design; color, icon size and sound also show variability. The Sampler Engine, added in version 2.0, lets students design and run probability simulations and plot the results over many samples. The program installs with more than 50 sample data sets, each with questions.

The publisher's site offers free activities in three sets (data analysis and modeling, randomness and chance, number sense), plus tutorials and movies. The data analysis set lists 11 activities for grades 5–8, each with a student worksheet and teacher notes citing Common Core standards. We read one, "Who Has the Heaviest Backpacks?": one class period, a 10-minute Think About It discussion, then 15 minutes of plotting at computers, with notes on student reasoning such as comparing groups of unequal size.

How these awards connect to this product

NSF award 9818946 (Konold, UMass Amherst, 1999–2005), titled "Tinker Plots: Tools and Curricula for Enhancing Data Analysis in the Middle School", funded development of the original software, first released in 2004; TinkerPlots.com says TinkerPlots is a result of the NSF-funded TinkerPlots project. The current version 3.0 (2020) was rewritten from scratch and is published by Learn Troop; no source we saved says who funded the rewrite. Konold's later NSF awards (0454754 on probability-modeling software; 0918653 and 0918735 on Data Games, whose games were embedded in TinkerPlots and Fathom) are not listed, because no source we saved says they funded TinkerPlots itself.
