Technologically Embodied Geometric Functions activities (Web Sketchpad)

Free browser activities in which students drag points to build and explore reflections, rotations, dilations and translations as functions, then connect them to linear functions and graphs.

  • Free, no login

Get the materialsgeometricfunctions.org

Before you use it

  • Free in the browser, with no login, purchase or advertising. Activities are CC BY-NC-SA 4.0; Web Sketchpad may be used freely only for non-commercial purposes. Students need devices with a current browser and web access.
  • No teacher notes: the site says none of these Web Sketchpad activities include teacher-support materials yet, so work through each activity yourself first. The original Dynamic Number versions have extensive teacher notes but need desktop Geometer's Sketchpad.
  • These are drafts. The developers say they are still revising them, and the Four Families activity and the unit summary are marked under construction. The pages were last updated 2015–2017, and the site calls itself a volunteer effort.
  • Time: each activity is expected to take one or two class periods.
  • Grade fit: the site doesn't state grade levels. The content (transformations as functions, function notation, linear functions and their graphs) points to middle and high school, and the second unit was featured in Mathematics Teacher.

What a teacher gets

Geometric Functions treats geometric transformations as functions: students drag a point (the independent variable) in Web Sketchpad and watch its image (the dependent variable) move. The introductory unit, Investigating Geometric Transformations as Functions, has activities on identifying functions and function families, one each on the reflect, rotate, dilate and translate families, and "function dances" in which a student drags a point to match the motion of a transformed image. Students use function notation, restrict a domain to a polygon and trace its range. A second unit, Connect Geometry and Algebra Through Functions, moves the transformations onto a number line, composes dilation and translation to build linear functions, and ends with dynagraph and Cartesian-graph puzzles.

Each activity is a web page with websketches, and most have a student worksheet; some include assessment games. The Reflection Family worksheet we checked gives step-by-step tool instructions and questions asking students to describe and sketch what they see. The site also lists algebra, complex-number and calculus activities and the original Dynamic Number activities for desktop Sketchpad.

How these awards connect to this product

The site's footer credits KCP Technologies' DRK-12 award 0918733 (Introducing Dynamic Number) and NC State's IUSE award 1712280. 0918733's outcomes report says the project developed 70 Sketchpad activities with teacher notes, including a topic it named Geometric Functions, and worked on Sketchpad for the web; the site's Dynamic Number page says many of the 12 Geometric Functions activities from that project are also in the Web Sketchpad units described here. So NSF funded the earlier desktop versions of these activities; no source says which award paid for the Web Sketchpad units themselves. 1712280 (Hollebrands, PI; Steketee and Scher, co-PIs) funded separate units for preservice secondary teachers, which its outcomes report places at geometricfunctions.org/fc, so it is not listed for this card. Scott Steketee is not a PI or co-PI on 0918733 (Scher, PI; Rasmussen, co-PI), though the record lists him as an author of a reported Mathematics Teacher publication; he is listed as a developer here because the site credits him with Scher on the Geometric Functions article in Mathematics Teacher.
