Before you use it

  • Free to download from a Google Site, with no account. Download the PDFs rather than opening them as Google Docs; the developers say that keeps the formatting.
  • This is a small-group intervention, not a whole-class unit. Plan on groups of three to six (about four is best) and 30–35 minute lessons three to four days a week, for eight or nine weeks (the program documents give both lengths).
  • You will need Google Slides to show the group, linking cubes, paper rectangles that can be torn or cut, and whiteboards or paper (the Task Set One lessons list these).
  • Start with the ten-task diagnostic interview, one-on-one or in a small group; the trajectory stages tell you which task set to begin with.
  • No grade level is stated. The lessons cite NCTM grades 3–5 number standards, and the scope-and-sequence maps the task sets to Common Core standards. The materials date from 2021.

What a teacher gets

FAACT is a free fraction intervention program written for teachers who work with small groups of students with learning disabilities or math difficulty. It is built on a learning trajectory for how these students come to understand fractions as quantities, and it has four parts: written descriptions of the six trajectory stages with student work, a diagnostic clinical interview of ten tasks with Teacher Noticing Guides, instruction, and development activities for students still building number concepts and multiplicative reasoning.

Instruction comes as a lesson guide template, four task sets (accessing fractions, unit fractions, non-unit fractions, and reversing non-unit fractions with parts of parts) and a decision guide that matches task sets to a student's stage. Each lesson runs Relate, Notice and Reflect, then Connect and Convince, with questioning prompts and talk moves for the teacher. Each task set has a sample lessons file; the Task Set One file holds four lessons, which use Google Slides, linking cubes and paper rectangles, and the Task Set Four file holds six.

How these awards connect to this product

The FAACT curriculum site says the work was funded by NSF Grant 1708327. The NSF records show Hunt's CAREER award under three numbers (1253254, 1446250, 1708327), all with the same FAACT title, at three different institutions in turn (the awardee changes from Utah State University to the University of Texas at Austin to North Carolina State University). The older NC State project page cites award 1708329; in the NSF API that number is an unrelated S-STEM capacity-building award, so we treat it as a typo for 1708327.
